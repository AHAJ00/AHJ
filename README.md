# RiskFlow ISO 31000

Application web autonome en français pour gérer les risques de bout en bout et suivre les incidents selon l'esprit du référentiel ISO 31000.

## Fichier à télécharger

Le fichier prêt à télécharger et à partager est : [`riskflow-iso31000-autonome.html`](riskflow-iso31000-autonome.html).

Il contient le HTML, le CSS et le JavaScript dans un seul fichier. Vous pouvez donc le copier, le télécharger, l'envoyer par e-mail ou l'ouvrir directement dans un navigateur moderne sans installer de serveur.

## Utilisation

1. Télécharger `riskflow-iso31000-autonome.html`.
2. Ouvrir le fichier dans un navigateur moderne.
3. Renseigner le contexte, les critères et le registre des risques.
4. Déclarer les incidents et les actions correctives.
5. Exporter les données en JSON/CSV ou utiliser **Télécharger PDF** pour imprimer/enregistrer le tableau de bord.

Les données sont stockées localement dans le navigateur avec `localStorage`; aucun serveur ni compte utilisateur n'est requis.

## Version de développement

Les fichiers `index.html`, `styles.css` et `app.js` restent disponibles séparément pour faciliter les modifications du code.
