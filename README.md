# AHJ

## Outil d’auto-évaluation ISO 37001

Application web autonome (HTML/CSS/JS) pour évaluer la maturité d’un système de management anti-corruption (ABMS) selon ISO 37001.

### Fonctionnalités
- Questionnaire complet multi-chapitres (Contexte, Leadership, Planification, Support, Opérations, Évaluation, Amélioration).
- Score de maturité pondéré (0 à 5) et conformité estimée (%).
- Dashboard visuel:
  - Radar de conformité par chapitre.
  - Histogramme des scores par chapitre.
  - Répartition des niveaux de maturité.
  - Heatmap de conformité par exigence.
- Plan d’actions priorisé avec délais recommandés.
- Sauvegarde/chargement local (localStorage).
- Export des résultats en JSON et CSV.

### Lancer l’outil
Ouvrir simplement `index.html` dans un navigateur moderne.
